# Documentation Index

This `docs/` folder contains the project READMEs and report files.

Files:
- `README_MODELING.md` — Modeling pipeline instructions and design choices.
- `README_STRUCTURE.md` — Project structure and where to find outputs.
- `REPORT.md` — Executive report summarizing models, visuals, and business impact.

How to use these files:
- Follow `README_MODELING.md` to run the modeling pipeline and reproduce results.
- Use `README_STRUCTURE.md` to quickly find outputs in `outputs/`.
- Share `REPORT.md` with stakeholders for a concise summary and recommended actions.
