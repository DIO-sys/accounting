# Project Structure ✅

Top-level (project root):
- `data.py` — data extraction and feature engineering (creates `x`, `y`, `dataset`, `features`, `targets`).
- `train_model.py` — runs the full training pipeline and writes models/plots to `outputs/`.
- `predict_example.py` — example: load a saved model and explain a single prediction.
- `summarize_shap.py` — writes SHAP feature ranking CSVs and short text explanations to `outputs/shap_reports/`.
- `shap_alerts.py` — applies simple rule-based alerts using predictions + SHAP contributions and writes `outputs/alerts/alerts.csv`.
- `README_MODELING.md`, `REPORT.md` — reports and instructions.

Outputs (generated by running `train_model.py` and support scripts):
- `outputs/models/` — trained model files (`model_{target}.joblib`).
- `outputs/plots/` — actual vs predicted, time-series, SHAP visualizations (all **human-readable titles**).
- `outputs/shap_reports/` — `feature_ranking_{target}.csv`, `explanation_{target}.txt`, and `shap_summary_table.csv` (feature names are plain English).
- `outputs/alerts/alerts.csv` — alerts generated from SHAP + rule engine (includes `target_label` and readable `reason`).
- `metrics_summary.csv` — training metrics (MAE, RMSE, R2) in project root (includes `target_label`).

How to re-run:
1) Install deps: `pip install -r requirements.txt`
2) Run training: `python train_model.py`
3) Summarize SHAP: `python summarize_shap.py` (creates/updates `outputs/shap_reports/`)
4) Run alerts: `python shap_alerts.py` (writes `outputs/alerts/alerts.csv`)

Where to find results (examples):
- Top SHAP drivers per target: `outputs/shap_reports/feature_ranking_*.csv` ✅
- Visuals for stakeholder slides: `outputs/plots/actual_vs_pred_*.png` and `outputs/plots/shap_summary_*.png` ✅
- Alerts (if triggered): `outputs/alerts/alerts.csv` ✅
